# Database Schema Documentation — Supabase PostgreSQL

The application uses **Supabase PostgreSQL** to persist candidate profiles, mock interview sessions, questions, answers, STAR feedback, prep flashcards, mentor shares, and 7-day practice plans.

---

## Supabase Database Setup & Migration

1. Create a project at [supabase.com](https://supabase.com).
2. Open the **SQL Editor** in your Supabase Dashboard.
3. Execute the contents of [`supabase/migrations/0001_init.sql`](file:///c:/Users/T.saatvik/Desktop/AI-Interview-Assistant/supabase/migrations/0001_init.sql).
4. Copy your credentials from **Project Settings → API**:
   - `Project URL` → `SUPABASE_URL`
   - `anon public` key → `SUPABASE_ANON_KEY`
   - `service_role` secret key → `SUPABASE_SERVICE_ROLE_KEY`
5. Paste these credentials into `backend/.env`.

## Supabase PostgreSQL Table Specs

### 1. `public.users`
Stores registered candidate and mentor accounts with hashed passwords and target career preferences.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique user ID |
| `name` | TEXT | NOT NULL | Candidate full name |
| `email` | TEXT | UNIQUE, NOT NULL | Account login email |
| `password_hash` | TEXT | NOT NULL | `bcryptjs` encrypted password hash |
| `target_role` | TEXT | DEFAULT 'Full Stack Developer' | Preferred role for mock interviews |
| `experience_level` | TEXT | DEFAULT 'Mid-Level (3-5 years)' | Candidate experience tier |
| `industry` | TEXT | DEFAULT 'Software & Technology' | Target industry domain |
| `bio` | TEXT | DEFAULT '' | Brief career summary |
| `skills_json` | TEXT | DEFAULT '[]' | JSON array of technical/soft skills |
| `target_jd` | TEXT | DEFAULT '' | Saved job description context |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Account registration timestamp |
| `updated_at` | TIMESTAMPTZ | DEFAULT NOW() | Profile update timestamp |

---

### 2. `public.interview_sessions`
Stores mock interview configuration, status, AI role explanation, overall performance scores, and 7-day action plans.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique session ID |
| `user_id` | BIGINT | REFERENCES `public.users(id)` ON DELETE CASCADE | Session owner |
| `title` | TEXT | NOT NULL | Display title |
| `target_role` | TEXT | NOT NULL | Role tested |
| `experience_level` | TEXT | NOT NULL | Experience tier tested |
| `industry` | TEXT | NOT NULL | Industry context |
| `interview_type` | TEXT | NOT NULL | Format (`Behavioural`, `Technical`, `Managerial`, `Case Study`, `HR`) |
| `job_description` | TEXT | DEFAULT '' | Custom job description context |
| `status` | TEXT | DEFAULT 'in_progress' | Session status (`in_progress`, `completed`, `archived`) |
| `overall_score` | INT | DEFAULT 0 | Aggregated score (0-100) |
| `duration_seconds` | INT | DEFAULT 0 | Practice duration in seconds |
| `summary` | TEXT | DEFAULT '' | Executive summary assessment |
| `strengths_json` | TEXT | DEFAULT '[]' | JSON array of strengths |
| `weaknesses_json` | TEXT | DEFAULT '[]' | JSON array of areas for growth |
| `improvement_plan_json` | TEXT | DEFAULT '[]' | JSON array of 7-day practice plan items |
| `role_explanation` | TEXT | DEFAULT '' | JSON object of Gemini role expectations |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Session creation timestamp |
| `updated_at` | TIMESTAMPTZ | DEFAULT NOW() | Last activity timestamp |

---

### 3. `public.questions`
Stores role-specific interview questions generated by Gemini AI.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique question ID |
| `session_id` | BIGINT | REFERENCES `public.interview_sessions(id)` ON DELETE CASCADE | Parent practice session |
| `question_number` | INT | NOT NULL | Sequence index |
| `question_text` | TEXT | NOT NULL | Prompt question text |
| `category` | TEXT | NOT NULL | Question category |
| `difficulty` | TEXT | NOT NULL | `Easy`, `Medium`, `Hard` |
| `expected_competencies_json` | TEXT | DEFAULT '[]' | JSON array of evaluated skills |
| `star_guidance` | TEXT | DEFAULT '' | STAR response tip |
| `is_follow_up` | INT | DEFAULT 0 | `1` if generated as adaptive follow-up |
| `parent_question_id` | BIGINT | DEFAULT NULL | Parent question ID |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Creation timestamp |

---

### 4. `public.answers`
Stores candidate responses submitted during simulated practice.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique answer ID |
| `question_id` | BIGINT | REFERENCES `public.questions(id)` ON DELETE CASCADE | Answered question |
| `user_id` | BIGINT | REFERENCES `public.users(id)` ON DELETE CASCADE | Candidate |
| `answer_text` | TEXT | NOT NULL | Response text |
| `duration_seconds` | INT | DEFAULT 0 | Seconds taken |
| `self_assessment_score` | INT | DEFAULT 3 | Self-assessment rating (1-5) |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Submission timestamp |

---

### 5. `public.feedback`
Stores Gemini AI structured evaluation metrics and improved STAR response models.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique feedback ID |
| `answer_id` | BIGINT | UNIQUE, REFERENCES `public.answers(id)` ON DELETE CASCADE | Evaluated answer |
| `relevance_score` | INT | NOT NULL | Relevance (1-100) |
| `clarity_score` | INT | NOT NULL | Communication clarity (1-100) |
| `evidence_score` | INT | NOT NULL | Quantifiable metrics score (1-100) |
| `star_score` | INT | NOT NULL | STAR structure score (1-100) |
| `confidence_score` | INT | NOT NULL | Confidence score (1-100) |
| `overall_score` | INT | NOT NULL | Aggregated question score (1-100) |
| `feedback_summary` | TEXT | NOT NULL | Executive feedback paragraph |
| `star_breakdown_json` | TEXT | NOT NULL | JSON object `{ situation, task, action, result }` |
| `improved_star_response` | TEXT | NOT NULL | Exemplar STAR model answer benchmark |
| `strengths_json` | TEXT | DEFAULT '[]' | Key strengths |
| `areas_for_improvement_json` | TEXT | DEFAULT '[]' | Actionable coaching recommendations |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Evaluation timestamp |

---

### 6. `public.prep_cards`
Stores candidate preparation flashcards for achievements, projects, strengths, and domain knowledge.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique card ID |
| `user_id` | BIGINT | REFERENCES `public.users(id)` ON DELETE CASCADE | Card owner |
| `session_id` | BIGINT | DEFAULT NULL REFERENCES `public.interview_sessions(id)` ON DELETE CASCADE | Associated session |
| `card_type` | TEXT | NOT NULL | `achievement`, `project`, `strength`, `knowledge` |
| `title` | TEXT | NOT NULL | Card title |
| `content_json` | TEXT | NOT NULL | JSON payload with talking points |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Creation timestamp |

---

### 7. `public.session_shares`
Stores explicit session sharing invitations for invited mentors.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique share ID |
| `session_id` | BIGINT | REFERENCES `public.interview_sessions(id)` ON DELETE CASCADE | Shared session |
| `shared_by_user_id` | BIGINT | REFERENCES `public.users(id)` ON DELETE CASCADE | Candidate who shared |
| `shared_with_email` | TEXT | NOT NULL | Mentor email |
| `share_code` | TEXT | UNIQUE, NOT NULL | Unique access code |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Invitation timestamp |

---

### 8. `public.practice_plans`
Stores 7-day personalized action plans generated upon completing interview sessions.

| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | BIGINT | PRIMARY KEY, GENERATED BY DEFAULT | Unique plan ID |
| `user_id` | BIGINT | REFERENCES `public.users(id)` ON DELETE CASCADE | Candidate owner |
| `session_id` | BIGINT | REFERENCES `public.interview_sessions(id)` ON DELETE CASCADE | Origin session |
| `title` | TEXT | NOT NULL | Plan title |
| `plan_days_json` | TEXT | NOT NULL | JSON array of 7 day focus areas & actions |
| `created_at` | TIMESTAMPTZ | DEFAULT NOW() | Creation timestamp |
